# Security Policy

## Reporting Security Issues

We take the security of Burhan Platform seriously. If you discover a security vulnerability, please do NOT create a public issue or discuss it publicly.

Please report security issues via:
- **GitHub Private Vulnerability Reporting:** On the repository, go to the **Security** tab and click **Report a vulnerability**.
- **Email:** Contact the security team directly at `security@ainux.online`.

Please include:
- A description of the issue and potential impact.
- Clear steps to reproduce the vulnerability (proof of concept).
- Any relevant logs or request/response examples.

We strive to acknowledge receipt of security reports within 48 hours and provide regular updates on remediation progress.
